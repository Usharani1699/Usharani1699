### Featured project

**[EV Battery Fleet Severity Index](https://github.com/Usharani1699/ev-battery-fleet-severity-index)**
Can one duty-cycle score predict battery ageing across lab cells and a 191-vehicle fleet? I tested it with battery-grouped and cross-chemistry validation: it separates fleet duty cycles well, but a model trained on LCO cells fell from R² 0.77 to R² −23 on unseen NMC cells.
`Python` `XGBoost` `SHAP` `scikit-learn` `time-series RUL`
